# DripeuszekFarm (Fabric 1.21.4, klient)
Wrzuć zawartość tego folderu do repo (folder `dripeuszekfarm` + `.github/workflows/build-farm.yml`).
Po buildzie w Actions pobierz artefakt `DripeuszekFarm` i wrzuć .jar do folderu mods (potrzebny Fabric API).

Klawisze: `.` menu | `K` włącz/wyłącz | `ENTER` zatwierdź punkt zaznaczenia.
Skrzynia: w menu "Skrzynia -> Zaznacz", spójrz na skrzynię i wciśnij ENTER.
